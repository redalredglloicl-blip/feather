# Zenith — v2

Zenith is our own on-device iPhone signer that fetches a real free Apple certificate
with the user's Apple ID, and signs and installs apps.
Everything is free, forever.

- **Version:** 2.0 (second build; v1 was version 2.9.0)
- **Theme:** peach `#FFC778` + dark mode, locked — no Appearance or App Icon settings
- **Language:** Iraqi Arabic UI, no emoji icons anywhere (hand-drawn SVG icons only)
- **Tabs:** Home / Certificates / Settings (Certificates is its own tab)
- **Features:** 30 saved features (favorites, expiry countdown ring, anti-revoke DNS
  profile, forced update with anti-tamper via Firebase, and more) — see the project notes.
- **Certificate:** one certificate signs all apps; one-tap renewal re-signs everything.
